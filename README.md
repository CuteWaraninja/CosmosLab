# 星际图谱 · CosmosLab

一个打开浏览器就能玩的中文宇宙探索小项目。可以转动星球、比较大小，走进地表场景看看海岸和岩石，也可以做几道天文趣味题。当前版本是 **V2.1**，下载后可以离线使用。

**这是一个纯 AI 提示词项目的第一次落地尝试。** 从想法到页面，再到海洋、地形和大气效果，项目通过自然语言提出需求、观察结果、继续修改的方式逐步完成。需求和反馈由项目发起者提供，代码实现、文档整理和检查由 AI 协助完成。这里的“纯 AI 提示词”描述的是开发方式，不代表贴图和科学资料都是 AI 生成的。详细说明见 [项目声明](AI_DISCLOSURE.md)。

## 为什么做它

起点很简单：希望天文知识不只是几段文字，而是能点开、转一转、比较一下的东西。

第一版先把星体资料和几个交互实验做出来，后来加入公开影像、真实大小对比和地表探索。V2.1 主要补了远处海洋、岩石层次和不同星球的大气清晰度。它还是一个边做边改的学习项目，画面和交互都有继续打磨的空间。

## 怎么打开

1. 在仓库的 [Releases](https://github.com/CuteWaraninja/CosmosLab/releases) 下载离线 ZIP，或者用 **Code → Download ZIP** 下载源码。
2. 先完整解压，再打开 `index.html`。
3. Windows 用户也可以双击 `启动星际图谱.cmd`。

不需要安装依赖、注册账号或启动服务器。请把 HTML、JS 文件和素材目录放在一起。推荐使用较新的 Edge、Chrome 或 Firefox；资料来源的外部链接需要联网。

## 目前能做什么

| 功能 | 内容 |
| --- | --- |
| 星体探索 | 13 个星体，支持搜索、旋转、缩放和物理档案 |
| 真实比例 | 同一尺度看星体大小，也可以选择任意两个星体比较 |
| 地表与大气 | 调整高度、环顾、移动、切换低纬和极区，观察岩石与水资源示意 |
| 海洋情景 | 用覆盖率控制海岸推进和低地淹没，观察远处海面、波纹和反光 |
| 大气清晰度 | 区分尘雾、浓雾和近真空环境，可调整视觉清晰度 |
| 知识挑战 | 36 道题，含大气、岩石与水、宇宙尺度和恒星探索等主题 |
| 物理与时间轴 | 质量、半径、密度、恒星颜色实验，以及宇宙演化梳理 |

进入星体后，点击“进入大气 / 地表探索”。拖动画面或用方向键环顾，`W / S` 前进后退，手机上可以使用屏幕按钮。海洋覆盖率需要先勾选“启用假设海洋覆盖情景”。

## 哪些是真实资料，哪些是示意

这一点比画面好不好看更重要。

- 部分球面使用 NASA 等公开影像或拼接地图，有些区域分辨率低、缺测，颜色也可能经过处理。并非每颗星体都有真实的全球表面照片。
- “真实比例”用于同尺视图和默认对比模式。单颗星体的特写会自动取景；位置和轨道间距没有按真实比例重建。
- 地形、岩石位置、海岸、云层和天气是程序生成的教学场景，不是实测高程、矿产分布图或大气流体模拟。
- 现实参考下，不给火星、月球等星体虚构已确认的液态地表海洋。冰、水蒸气和推测中的地下海洋会分别说明。
- 假设海洋覆盖率是演示参数，局部画面占比不等于全球覆盖率，也不能直接换算成储水量。清晰度中的距离同样是视觉参数，不是天气预报。
- 巨行星没有可供普通着陆的固体地面；恒星场景也不是岩石地表。

详细出处见 [第三方素材说明](THIRD_PARTY_NOTICES.md) 和 [原始影像记录](assets-sources.txt)。这个项目与 NASA 没有隶属或背书关系。

## 本地检查与开发

运行本身没有构建步骤。有 Node.js 时，可以执行：

```sh
node scripts/check.mjs
```

这个检查覆盖脚本语法、页面引用文件、题库结构和关键数据；它不代替真实浏览器测试。发布前的人工检查项见 [贡献指南](CONTRIBUTING.md)。

主要文件：

```text
index.html          页面、星体数据和基础实验
upgrade.js          球面展示、交互、题库和探索入口
worlds.js           星体环境资料与新增题目
environment.js      海洋情景与大气清晰度设置
terrain-v21.js      V2.1 地形、海洋和岩石绘制
terrain.js          保留的 V2 地形实现，V2.1 不加载
textures.js         嵌入图片，便于直接离线打开
assets/             影像副本
```
